# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository when available, or contact
the repository owner through their GitHub profile.

Include the affected file or workflow, reproduction steps, impact, and any
suggested remediation. Do not include real credentials or user data.

WebToMobile is a local, skills-only plugin. It does not operate a hosted service
or collect telemetry. The skills can instruct an AI coding agent to read and
edit the project the user places in scope, subject to that agent's permissions.
